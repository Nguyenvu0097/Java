# Lab 4 - Java SwingWorker

Gồm đúng 10 bài theo đề Lab 4:
1. Đồng hồ đếm ngược
2. Mô phỏng tải dữ liệu
3. Tổng số nguyên tố
4. Fibonacci Memoization
5. Đếm số dòng file
6. Hủy tác vụ
7. Tìm kiếm từ khóa trong file
8. CSV điểm sinh viên
9. Tải danh sách sản phẩm
10. Quản lý sản phẩm CSV

## Chạy bằng Maven
Yêu cầu JDK 17+ và Maven.

```bash
mvn clean compile
mvn exec:java -Dexec.mainClass="vn.edu.eaut.lab4.App"
```

Nếu Maven chưa có exec plugin, có thể chạy `App.java` trực tiếp trong IDE.
