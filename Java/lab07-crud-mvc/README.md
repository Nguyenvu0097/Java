# Lab 7 – CRUD Servlet + JSP + MVC
Project đã chia đúng 13 bài theo đề Lab 7. Các bài 1–5 là phần có code gợi ý; các bài 6–13 là phần mở rộng/tự làm. Ba module CRUD chạy mẫu là Sinh viên, Sách và Sản phẩm.
Tài khoản: admin/123456, user/123456.
Build: `mvn clean package`
WAR: `target/lab07-crud-mvc.war`
Deploy vào: `apache-tomcat-10.x/webapps/`
URL: `http://localhost:8080/lab07-crud-mvc/`
Lưu ý: dữ liệu CRUD dùng List trong bộ nhớ, chưa dùng CSDL.
